# KING · 모프

여러 사용자의 의견과 조건을 모아 LLM으로 안건을 정리하고, 함께 의사결정을 돕는 앱입니다.

## 개발 동기와 기대 효과

그룹에서 서로 다른 의견을 모으고 비교하는 과정을 간소화하기 위해 기획했습니다. 각자의 의견을 정리하고 안건별 결과와 최종 요약을 제공해 논의 시간과 기록 부담을 줄이는 것이 목표입니다.

## 예정된 화면 흐름

- 이메일·비밀번호 로그인 및 회원가입
- 시작 화면: 방 만들기, 방 들어가기, 환경설정
- 방 만들기: 인원수, 그룹 이름, 주제 설정 후 무작위 참여 코드 발급
- 방 들어가기: 참여 코드 입력
- 방 내부: 조건 입력 → 사용자별 의견 입력 → 결과와 상세 정보 확인
- 다른 안건 시작: 조건 입력 화면으로 이동
- 종료: 최종 결과 요약본 확인

## 예정된 데이터 흐름

사용자 입력 → LLM 전처리 → 데이터베이스 저장 → 서버에서 저장된 정보를 LLM에 전달 → 결과 저장 → 출력

데이터 저장 및 서버 구성 후보: Supabase, Railway, Heroku.

## 현재 상태

프로젝트 폴더와 기획 요약만 생성한 초기 저장소입니다. 앱 구현은 아직 시작하지 않았습니다.
